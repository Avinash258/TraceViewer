# Contributing

Thanks for your interest.

## How to contribute

1. Fork the repository and create a branch (`chore/...`, `fix/...`, `docs/...`).
2. Keep changes focused; do not commit secrets, reports, or `node_modules`.
3. Open a pull request with a clear description of the problem and fix.
4. Ensure tests (if present) pass locally before requesting review.

## Code of conduct

Be respectful. This is a professional QA / automation portfolio project.
